# 台股夜盤 Taiwan Market Monitor

一個以台灣股市為核心的靜態儀表板，整合大盤走勢、法人動向、全球市場與時事快報，部署於 GitHub Pages。

## 功能

- **大盤總覽**：加權指數走勢（可切換區間）、均線、盤勢摘要與市場開休市狀態
- **法人動向**：三大法人買賣超
- **台股焦點與個股排行**：成交值、漲幅、跌幅排行
- **全球市場**：主要股市指數、匯率、利率與大宗商品
- **時事快報**：彙整財經新聞，並標示重大消息
- **總體經濟指標**：選用功能，需自行設定資料來源金鑰
- **日夜主題**：支援夜間與晨間兩種外觀，自動適應手機與桌機

## 運作方式

```
定時排程 ──> 取得公開資料 ──> 產生 data.json ──> 靜態網頁讀取並呈現
```

網頁本身不直接連線任何需要金鑰的服務，所有資料皆由排程預先整理成靜態檔案，因此前端不含任何憑證。

## 專案結構

| 檔案 | 說明 |
|---|---|
| `index.html` | 儀表板前端頁面 |
| `fetch_data.py` | 資料整理腳本 |
| `data.json` | 由排程自動產生的資料檔 |
| `.github/workflows/update.yml` | 自動更新排程 |
| `requirements.txt` | Python 相依套件 |

## 在自己的帳號部署

1. Fork 或複製本專案至自己的 GitHub 帳號
2. 於 Settings → Pages 啟用 GitHub Pages
3. 於 Settings → Actions → General 將 Workflow permissions 設為 Read and write
4. 於 Actions 頁面手動執行一次 `update-data`
5. 前往 `https://<你的帳號>.github.io/<專案名稱>/` 檢視

選用的資料來源金鑰請一律透過 GitHub 的 Secrets 設定，**切勿寫入程式碼或提交至儲存庫**。

## 自訂

追蹤的標的清單位於 `fetch_data.py` 開頭，可自行增減。
